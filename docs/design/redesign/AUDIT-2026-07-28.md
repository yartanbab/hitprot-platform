## S1 — Bootstrap semantic utility'leri token'a bağlı DEĞİL 🔴

`apya-theme-bridge.css` yalnız `--bs-primary-rgb`'yi köprülüyor:

```css
--bs-primary:     var(--apya-accent-500);
--bs-primary-rgb: 79, 70, 229;      /* ✅ */
--bs-success: var(--apya-positive-500);   /* ❌ -rgb yok */
--bs-danger:  var(--apya-negative-500);   /* ❌ -rgb yok */
--bs-warning: var(--apya-warning-500);    /* ❌ -rgb yok */
--bs-info:    var(--apya-brand-400);      /* ❌ -rgb yok */
```

Bootstrap 5.3'te renk utility'leri **`-rgb` değişkenini** okur:

```css
.text-success { color: rgba(var(--bs-success-rgb), var(--bs-text-opacity)) !important; }
.bg-danger    { background-color: rgba(var(--bs-danger-rgb), var(--bs-bg-opacity)) !important; }
```

`--bs-success` (hex) override'ı bu utility'lere **hiç ulaşmıyor**. Sonuç:

| Sınıf | Fiilen basılan | Olması gereken (light) | Olması gereken (dark) |
|---|---|---|---|
| `.text-success` | `#198754` (BS yeşili) | `#059669` | `#10B981` |
| `.text-danger` | `#DC3545` (BS kırmızısı) | `#DC2626` | `#F87171` |
| `.text-warning` | `#FFC107` (BS sarısı) | `#D97706` | `#FBBF24` |
| `.text-info` | `#0DCAF0` (BS camgöbeği) | `#60A5FA` | `#60A5FA` |

Kullanım envanteri (`Pages/` + `wwwroot/js/`):
`text-danger` 50 · `text-success` 32 · `text-warning` 17 · `bg-warning` 14 · `bg-danger` 10 · `bg-success` 8 · `border-warning` 7 · `text-info` 4 · `border-danger` 4 …

**Dark temada ayrıca a11y sorunu:** `#DC3545` `#0F0F11` üstünde ~4.0:1 (AA altı); token'ın dark karşılığı `#F87171` ~7:1.

**Aksiyon:** `-rgb`, `-bg-subtle`, `-border-subtle`, `-text-emphasis` değişkenlerini light + dark köprüle. Tek noktadan ~250 kullanım düzelir; DOM'a dokunulmaz.

## S3 — `_KpiCard` token-driven değil 🔴

```cshtml
<div class="kpi-icon-box bg-@Model.Accent bg-opacity-10 text-@Model.Accent me-3">
```

`Accent` değerleri Bootstrap adları: `primary` 7 · `success` 6 · `warning` 5 · `info` 4 · `danger` 3.
S1 yüzünden ikon kutuları **Bootstrap paletiyle** boyanıyor; dark temada `bg-opacity-10` pastel zemin + doygun metin düşük kontrast veriyor (tokens.css'in dark'ta `-50/-100` tonlarını saydama çevirmesinin sebebi tam olarak bu).

**Aksiyon:** `.kpi-icon-box--{accent,positive,negative,warning,brand,ai,neutral}` ton sınıfları (chip'lerle aynı `color-mix` deseni), `KpiCardModel.Accent` → semantic isimler + eski Bootstrap adlarından geriye-uyumlu eşleme.

### Canlı QA'da bulunan 2 ek gerçek bug (denetim sırasında değil, ölçümde çıktı)

1. **`.alert-*` LeptonX tarafından ezilmiş.** LeptonX'in derlenmiş bundle'ı `.alert-{varyant}`ı ikinci kez tanımlayıp `background`/`color`u **sabit** yazıyor (`color:#686B6E`, link/ikon `#161616`). Bu yüzden `-bg-subtle` köprüsü alert'lere hiç ulaşmıyordu ve **11 alert kutusu dark temada okunmuyordu**. Bridge'e geri-alma bloğu eklendi.
2. **Metin tonu ≠ dolgu tonu.** `--bs-{ton}-rgb` köprüsü hem `.bg-*` hem `.text-*` tarafından okunuyor ve ikisine de `-500` (dolgu tonu) veriyor → beyaz üstünde `.text-warning` **2.92:1**, `.text-info` **2.33:1**, `.text-success` **3.46:1** (WCAG AA = 4.5:1). tokens.css bunun için ayrı `--apya-text-*` metin token'ları tanımlıyordu ama Bootstrap utility'leri onları kullanmıyordu. Metin utility'leri metin tonuna bağlandı; ayrıca `.apya-chip-brand` (4.47:1 → ~6.5:1) ve dark `.apya-chip-accent` (3.99:1 → ~8:1) düzeltildi.
