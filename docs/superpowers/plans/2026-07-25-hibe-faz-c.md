## Domain (yeni + genişletme)

- `Domain.Shared/Grants/GrantDisbursementTrancheStatus.cs`: `Planlandi=0, TalepEdildi=1, Odendi=2`.
- `Domain/Grants/GrantDisbursementTranche.cs` (`FullAuditedAggregateRoot<Guid>, IMultiTenant`): `GrantApplicationId`, `SequenceNo (int)`, `Amount (decimal)`, `Status (GrantDisbursementTrancheStatus)`, `DueDate (DateTime?)`. Domain metodu: `MarkPaid()`.
- `Domain/Grants/GrantMilestone.cs` (aynı taban): `GrantApplicationId`, `Title (string, maxLen 128)`, `DueDate (DateTime?)`, `IsCompleted (bool)`. Domain metodu: `Complete()`.
- `GrantApplication` genişletme: `ApprovedAmount (decimal?)` eklenir; `Stage` setter **private** olur (mevcut public setter kırılır — dışarıdan sadece `AdvanceStage` ile değişir, DTO okuma yönü ObjectMapper.Map ile etkilenmez). Yeni domain metodu:
  ```csharp
  public void AdvanceStage(GrantApplicationStage stage, decimal? approvedAmount = null)
  {
      Stage = stage;
      if (approvedAmount.HasValue) ApprovedAmount = approvedAmount;
  }
  ```
- Testler: `GrantApplication_Tests.cs` — `AdvanceStage` Stage+ApprovedAmount günceller; `approvedAmount` verilmezse mevcut değer korunur.

## Application

- `GrantApplication` domain metodu üzerinden `GrantApplicationHostAppService` (host, `[Authorize(Grants.Edit)]`, `CurrentTenant.Id!=null` reddeder — B3 `EnsureHostContext` deseni):
  - `GetListAsync`: tüm tenant'ları `ICurrentTenant.Change` ile gezip (B3 `FirmSignalsBuilder`/`GrantHostDispatchAppService` deseni) her tenant'ın başvurularını + tenant adını + call/grant bilgisini toplar.
  - `AdvanceStageAsync`: ilgili tenant bağlamına geçip (`_currentTenant.Change(app.TenantId)` — önce filtre-kapalı ile application'ı bulup TenantId'sini öğren, sonra o bağlamda `AdvanceStage` çağırıp kaydet) `app.AdvanceStage(...)`.
  - Tranche/Milestone CRUD: aynı tenant-context-değiştirme deseniyle ilgili `GrantApplication`'ın altına ekle/güncelle/sil.
- `GrantApplicationAppService` (tenant): `GetMyApplicationsAsync` artık `Tranches`/`Milestones`/`ApprovedAmount` da dolduruyor (salt okuma). Yeni `GetMyDashboardAsync`: kendi başvurularından KPI'ları hesaplar + `GrantRecommendationAppService`'teki açık çağrı listesinden (in-process çağrı, DI ile enjekte) en yakın son tarihleri + kendi milestone'larını birleştirip "Yaklaşan Son Tarihler" oluşturur (üstten 5, tarihe göre artan).
